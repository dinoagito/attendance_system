## API Endpoints

```
📍 GET  /visitor/register
   ➜ Display registration form and today's visitor list

📍 GET  /visitor
   ➜ API: Get all today's visitors (JSON response)

📍 POST /visitor
   ➜ API: Create new visitor record with photo

📍 POST /visitor/{id}/checkout
   ➜ API: Record visitor checkout time
```

## Database Schema

```sql
visitors table:
├── id (PK)
├── full_name
├── phone
├── person_to_visit (FK → employees.id)
├── purpose
├── remarks
├── date
├── time_in
├── time_out (nullable)
├── photo_path
├── created_at
└── updated_at
```
